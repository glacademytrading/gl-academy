Regra de ouro: loop sem som e sem controles só nas peças curtas e decorativas; o que tem legenda vai com botão de play. Os loops só começam quando aparecem na tela, então não pesam o carregamento.

Código para o Codex

Cole no Codex junto com os arquivos do kit. Ajuste os caminhos para a pasta onde os vídeos ficarem.

<!-- Loop decorativo: sem som, em loop, só toca quando aparece na tela -->
<video class="gl-loop" muted loop playsinline preload="none" poster="/videos/site-loop-tradingview.jpg">
  <source src="/videos/site-loop-tradingview.mp4" type="video/mp4">
</video>

<!-- Círculos da página Escolha: o mesmo loop, recortado redondo -->
<video class="gl-loop gl-circulo" muted loop playsinline preload="none" poster="/videos/site-circulo-pacote.jpg">
  <source src="/videos/site-circulo-pacote.mp4" type="video/mp4">
</video>

<!-- Vídeo com legenda: com botão de play -->
<video controls playsinline preload="none" poster="/videos/site-pacote-completo-16x9.jpg">
  <source src="/videos/site-pacote-completo-16x9.mp4" type="video/mp4">
</video>

<style>
  .gl-loop { width: 100%; height: auto; display: block; }
  .gl-circulo { aspect-ratio: 1; border-radius: 50%; object-fit: cover; }
</style>

<script>
  // Os loops só carregam e tocam quando aparecem na tela.
  // Com "reduzir movimento" ligado no aparelho, fica a imagem parada.
  const reduzir = matchMedia('(prefers-reduced-motion: reduce)').matches;
  const glLoops = new IntersectionObserver(entradas => entradas.forEach(({ target: video, isIntersecting }) => {
    if (isIntersecting && !reduzir) video.play().catch(() => {});
    else video.pause();
  }), { threshold: 0.25 });
  document.querySelectorAll('video.gl-loop').forEach(video => glLoops.observe(video));
</script>
