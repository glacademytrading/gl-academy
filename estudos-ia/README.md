## Como contribuir

1. Copie o modelo em [`_templates/nota-de-estudo.md`](_templates/nota-de-estudo.md).
2. Salve na trilha certa com o nome `AAAA-MM-DD-assunto.md`
   (ex.: `02-llms-e-prompts/2026-10-06-engenharia-de-prompt.md`).
3. Adicione o link no índice da trilha (o `README.md` de cada pasta).
