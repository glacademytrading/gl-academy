# Jornada do aluno (protótipo)

Protótipo clicável do caminho depois da compra do GL Club IA. Abra `index.html` e use a barra do topo para pular entre as telas.

1. Pré-checkout (captura de dados antes do pagamento)
2. Oferta adicional no checkout
3. Página de obrigado
4. Verificar compra pelo e-mail
5. Código de 6 dígitos
6. Criar senha
7. Perfil do aluno (pesquisa obrigatória de 7 perguntas)
8. Recomendação de parceiro (afiliado)
9. Painel do aluno, com trilha recomendada a partir do perfil

Nada é enviado nem salvo: é um protótipo para validar fluxo e texto antes de construir a área de membros de verdade.
