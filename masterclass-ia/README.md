# Masterclass de Agentes de IA (esboço)

Página de captação de uma live gratuita sobre agentes de IA para negócios.
Abra `index.html` no navegador. O logo vem de `../logo-gl.png`.

Os trechos marcados com borda tracejada (classe `fill`) ainda precisam de informações reais.
