# Conceitos (glossário canônico)

Definições como o curso as usa. Se o curso usa um termo de forma diferente do mercado, vale a do curso,
com a diferença anotada.

Modelo:

```
### C-0001 — Termo
- definição: (literal ou paráfrase fiel)
- fontes: FONTE-0001 @ p.12; FONTE-0003 @ 00:14:20
- sinônimos / termos do curso:
- não confundir com:
- usado em regras: R-xxxx
- status: explicito | inferido | revogado
```
