# Mentoria GL Academy: Operacional na Prática

Formato: vídeos rápidos e diretos, de **3 a 6 minutos**, cada um com um único objetivo prático.

## Grade (rascunho, fechada depois do levantamento dos indicadores)

| Módulo | Tema | Vídeos |
|--------|------|--------|
| 0 | Boas-vindas e visão geral do GL Model | 1–2 |
| 1 | Instalação e configuração dos indicadores | 1 por plataforma |
| 2+ | Um módulo por indicador: função → leitura → aplicação | 2–4 por indicador |
| N-1 | Montando o operacional completo (indicadores combinados) | 2–3 |
| N | Gestão de risco, rotina diária e checklist de operação | 2–3 |
