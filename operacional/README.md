# Operacional GL Academy

Organização dos indicadores da GL Academy: código-fonte, material educacional,
tutoriais de uso e a mentoria prática (vídeos curtos de 3 a 6 minutos).

## Estrutura

```
operacional/
├── indicadores/            # um diretório por indicador
│   └── <nome-do-indicador>/
│       ├── codigo/         # código-fonte organizado e comentado
│       ├── README.md       # ficha técnica: função, objetivo, parâmetros, sinais
│       └── tutorial.md     # passo a passo de instalação e uso
├── templates/              # modelos padrão (ficha do indicador, roteiro de vídeo)
└── mentoria/               # grade da mentoria e roteiros dos vídeos
```

## Fluxo de trabalho

1. **Código:** receber o código de cada indicador, padronizar nomes,
   parâmetros e comentários e registrar a versão.
2. **Material educacional:** preencher a ficha técnica
   (`templates/ficha-indicador.md`): o que é, para que serve, como ler os sinais.
3. **Tutorial de uso:** instalação na plataforma, configuração recomendada,
   exemplos de entrada, saída e gestão de risco.
4. **Mentoria:** resumir função, objetivo e forma correta de uso de cada
   indicador e montar a grade de vídeos de 3 a 6 minutos
   (`templates/roteiro-video.md`).
